## Project Summary
A visually striking and innovative website for Mkhize NP Physiotherapy Inc., a professional physiotherapy practice based in South Africa (Pietermaritzburg and Hammarsdale). The site focuses on rehabilitation, home visits for bed/wheelchair-bound patients, and empowering patients through education and holistic treatment.

## Tech Stack
- Framework: Next.js 15 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- Animation: Framer Motion
- Icons: Lucide React
- Deployment: Vercel (implied)

## Architecture
- `src/app`: Page routes and layouts
- `src/components`: Reusable UI components (Navbar, Hero, Services, InteractiveUX)
- `src/lib`: Utility functions

## User Preferences
- **Aesthetic**: White background, clean, modern, professional, yet warm.
- **Email**: enquiries@mkhizephysio.co.za
- **UX**: Innovative and clever, exceeding normal template standards.
- **Brand Colors**: Blues (from logo), White.
- **Focus**: The practice as a whole, not just the founder.
- **Core Concept**: Rehabilitation and "facilitating the body's capacity to heal itself".
- **Language**: UK English spelling (e.g., specialised, colour, organisation)

## Project Guidelines
- No technical jargon where possible.
- High visual accuracy with brand assets.
- Mobile-first, responsive design.
- Use Framer Motion for smooth, "rehabilitative" transitions.

## Common Patterns
- Component-based structure.
- Accessible ARIA labels.
- Responsive grids and flexboxes.
